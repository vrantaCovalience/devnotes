# 👩‍💻 Participant-Focused Roadmap

## What You’ll Learn in This Workshop
✅ Debugging & learning with Copilot Ask Mode  
✅ Setting up instructions & Context7 MCP for smarter context  
✅ Using Agent Mode to build features step by step  
✅ Generating docs automatically  
✅ Planning with custom chatbot  
✅ Reviewing & refactoring with AI assistance  

---

## Step-by-Step Agenda

1. Fix a TypeScript issue with Ask Mode in `login/page.tsx`.
2. Build a **custom API hook** with Ask Mode.
3. Create **`instructions.md`** to guide Copilot.
4. Use **Agent Mode** to build:
   - Notes Database Schema
   - Notes API Endpoints
5. Add **`coding-standard.instruction`** + refine `instructions.md`. And explain how anyone can create those files.
6. Learn & enable **Context7 MCP** for better context.
7. Build **dashboard page** listing notes (first step only).
8. Auto-generate **documentation** inside `docs/`.
9. Create a **custom chatbot** to plan dashboard improvements.
10. Use Agent Mode to implement:
    - Note Creation
    - Note Editing
    - Note Management
11. Run Copilot **Review + Refactor** on a file.

---

🎯 **End Goal**: You’ll see how Copilot + MCP can support **debugging, coding, planning, documenting, and reviewing** — all inside your dev workflow.
